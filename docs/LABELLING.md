# Value labelling rules

Every number, score, range, and evaluative statement rendered anywhere in the
interface carries **exactly one** provenance label. The label set is fixed in
`src/types/labels.ts`; adding a label requires updating this document too.

| Label | Use it when | Example |
| --- | --- | --- |
| **From your answer** | The value is what the user typed or selected, unmodified. | "Deadline: 1 quarter" |
| **Derived from your answers** | The value is computed by the published rules in `src/engine`. | A dimension score of 72/100 |
| **Estimate** | A calculated range that is indicative, not measured or quoted. | "Effort: 40–95 hours" |
| **Assumption** | A default the prototype applied because the information was missing. | "Assumes 6 builder hours per week" |
| **Demonstration data** | Fictional sample content included so the interface can be shown. | Demo scenario answers and sample metrics |
| **Unknown** | Not supplied and not inferred; recorded as an open question. | "Source of truth: unknown" |
| **Requires verification** | Must be confirmed with a real source, vendor, or specialist. | Any subscription or hosting price |

## Hard rules

1. **No bare figures.** A number without a label is a defect. Tests assert this
   for report sections as they are built.
2. **Ranges over point values** for anything estimated. A single number reads as
   precision the prototype does not have.
3. **No invented money.** No hourly rate, subscription price, or hosting price is
   ever generated by the prototype. Cost output is effort hours plus cost
   *categories* until the user supplies confirmed figures. Every cost block shows
   "Pricing must be verified before implementation."
4. **Demonstration data is visually distinct** and never presented as a real
   record, quote, or measurement.
5. **Colour is never the only signal.** Labels and statuses always carry text.
6. **Unknowns are surfaced, not hidden.** Anything skipped during intake appears
   in the report's Unknowns list and reduces the stated confidence level.
